Projeto John Wick

Projeto acadêmico desenvolvido utilizando HTML5 e CSS3, com o objetivo de praticar a criação de páginas web, formulários, tabelas, imagens e links.

Sobre o projeto

A página apresenta uma pequena introdução sobre a história do personagem John Wick, utilizando imagens, textos e uma tabela com informações sobre os filmes da série.

Também foi desenvolvido um formulário para que o usuário possa selecionar seu filme e gênero favoritos.

Como executar

Para executar o projeto, basta abrir o arquivo Page_1.html em um navegador.

As imagens utilizadas devem estar na mesma pasta do arquivo HTML para serem carregadas corretamente.
